# Music licences

Both tracks are from one OpenGameArt page, written by the composer as a pair: the calm version
for the base, the action version for battle, meant to crossfade from the calm into the start of
the action.

## base.ogg: Gravity Turn (calm)

- **Composer:** vitalezzz
- **Source:** https://opengameart.org/content/gravity-turn (file `gravity_turn_calm_0.flac`)
- **Licence:** CC0 1.0 Universal, https://creativecommons.org/publicdomain/zero/1.0/
- **Fetched:** 2026-10-29
- **Credit:** optional under CC0; the page's attribution notice reads "Vitalezzz - Gravity Turn".
- **Processing:** the composer's loop file kept whole (7,815,877 frames, 177.231 s: 96 bars at
  130 BPM, so the loop is the whole file); a 10 ms raised-cosine fade-out on the last 441 frames
  so the cut tail meets the file's silent first sample without a click; a plain gain of
  -0.5 dB to -18 LUFS integrated, true peak -6.2 dBTP; encoded to Ogg Vorbis with `oggenc`
  (vorbis-tools 1.4.3, `-q 4`, about 115 kb/s), 44.1 kHz stereo.
